# Shalom.portfolio

A modern, responsive personal portfolio website showcasing my full-stack web development projects, skills, and experience.

## 🚀 Tech Stack

- **Frontend:** React, Tailwind CSS (v4)
- **Build Tool:** Vite
- **Deployment:** Vercel

## ✨ Key Features

- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Clean UI:** Built with Tailwind CSS for modern, customizable styling.
- **Fast Performance:** Powered by Vite for minimal load times and quick rendering.
